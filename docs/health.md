# Health API

## `GET /health`

Checks backend health and database connectivity.

### Auth

Not required.

### Response

```json
{
  "status": "ok",
  "database": "connected",
  "timestamp": "2026-05-16T12:00:00.000Z"
}
```

### Fields

| Field | Type | Description |
| --- | --- | --- |
| `status` | string | Backend status. Currently always `ok`. |
| `database` | string | `connected` or `disconnected`. |
| `timestamp` | string | ISO timestamp generated by the backend. |
